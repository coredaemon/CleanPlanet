## Что не получилось или осталось ограничением

### Не удалось проверить GitHub Actions из терминала

Команда `gh` недоступна на машине:

```text
gh not installed
```

Поэтому статус GitHub Actions / Pages после push не был проверен из терминала.

### Нет реального домена

В `astro.config.mjs` пока указан временный домен:

```ts
site: 'https://cleanplanet.example'
```

Из-за этого в собранных HTML-файлах, canonical, Open Graph и sitemap остаётся `https://cleanplanet.example`.

Для финального SEO-релиза нужно:

1. Получить реальный домен.
2. Заменить `site` в `astro.config.mjs`.
3. Выполнить `npm run build`.
4. Пересобрать архив для хостинга.

### Пакет для хостинга не закоммичен

Файлы:

- `hosting-package/cleanplanet-hosting.zip`
- `hosting-package/README-hosting.txt`

оставлены локально и не добавлены в Git.

Это сделано намеренно, чтобы не коммитить бинарный архив и временный пакет доставки в репозиторий.

### Telegram-уведомления форм не подключены полностью

На сайте добавлены ссылки на Telegram `@CleanPlanet1`.

Но серверная отправка заявок в Telegram через бота зависит от `api/config.php`.

По проверке:

- `telegram_bot_token` не заполнен;
- `telegram_chat_id` не заполнен.

Чтобы заявки уходили в Telegram-чат, нужно добавить bot token и chat id в `public/api/config.php` локально и на хостинге.

Секреты нельзя коммитить в Git.

### Email и production-настройки нужно проверить на хостинге

В `api/config.php` есть настройки отправки заявок, но перед реальным запуском нужно проверить:

- рабочий email получателя;
- корректный `from_email`;
- работает ли `mail()` на выбранном хостинге;
- разрешены ли исходящие HTTPS-запросы из PHP для Telegram.

### Архивация сначала не прошла

Первая попытка создать zip-архив завершилась ошибкой из-за открытого файлового дескриптора от локального dev-сервера.

Dev-сервер был остановлен, после этого архив успешно создан.

### Локальный запуск dev-сервера сначала не прошёл через `npm`

Первая попытка `Start-Process` с `npm` завершилась ошибкой Windows.

После запуска через `npm.cmd` dev-сервер успешно поднялся.
