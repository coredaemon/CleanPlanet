# Деплой на хостинг по FTP

Домен: **clean-planet.online**

## 1. Собрать сайт

```bash
npm run build
```

Готовый сайт — в папке `dist/`. Заливать нужно **содержимое** `dist/`, а не саму папку.

## 2. Залить по FTP

Куда: корень сайта на хостинге — обычно `public_html/`, `www/` или `htdocs/`.

⚠️ **Включите в FTP-клиенте показ скрытых файлов**, иначе не зальётся `.htaccess`
(он начинается с точки, FileZilla и большинство клиентов прячут такие файлы по умолчанию).

- FileZilla: Сервер → Принудительно отображать скрытые файлы
- WinSCP: Настройки → Панели → Показывать скрытые файлы

Без `.htaccess` не будут работать: редирект на HTTPS, склейка www, страница 404,
сжатие и кеширование, защита конфига.

## 3. Проверить на хостинге

- [ ] PHP включён (нужен для формы заявок), версия 7.4+
- [ ] Файл `api/config.php` залился и содержит правильный `lead_email`
- [ ] Корень сайта доступен на запись (PHP создаёт папки `uploads/` и `api/leads/`)
- [ ] Открыть `https://clean-planet.online/api/config.php` — должно быть **403 Forbidden**
      (если показывает содержимое — сообщите, настроим запрет иначе)

## 4. Почта для заявок

В панели хостинга завести ящик **noreply@clean-planet.online** — он указан в
`api/config.php` как отправитель. Отправка от адреса на своём домене нужна,
чтобы письма проходили SPF/DKIM и не улетали в спам.

Заявки приходят на **Katufka427@mail.ru** (задаётся в `api/config.php`, на сайте не отображается).

### Резервный канал (рекомендуется)

Если письмо не уйдёт, заявка не потеряется — она пишется в `api/leads/leads.log`
(папка закрыта от доступа снаружи). Но чтобы узнавать о заявках сразу, лучше
подключить Telegram: создать бота через @BotFather и вписать в `api/config.php`:

```php
'telegram_bot_token' => '...',
'telegram_chat_id'   => '...',
```

## 5. Обязательный тест после заливки

1. Открыть сайт — проверить, что работает HTTPS и нет www.
2. Отправить **тестовую заявку** через форму.
3. Убедиться, что письмо пришло и **читается по-русски** (не кракозябрами).
4. Открыть несуществующий адрес (`/abc/`) — должна показаться страница 404 сайта.

Если форма покажет «Не удалось отправить заявку» — значит `mail()` на хостинге
не работает; тогда подключаем Telegram или SMTP.

## 6. После запуска

- Подключить Яндекс.Метрику: вписать номер счётчика в `src/data/contacts.ts`
  (`analytics.yandexMetrikaId`) и пересобрать. Счётчик грузится только после
  согласия в cookie-баннере — это требование 152-ФЗ.
- Добавить сайт в Яндекс.Вебмастер, отправить `sitemap-index.xml`.

## Что менять при смене домена

Домен задаётся в двух местах:
1. `astro.config.mjs` → `site`
2. `public/robots.txt` → строка `Sitemap:`

Плюс `from_email` в `public/api/config.php`. Везде остальное подтягивается автоматически.
